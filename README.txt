MENNA MOHAMED — MODERN BACKEND .NET PORTFOLIO

Folder structure:
- index.html
- css/style.css
- js/script.js
- assets/images/profile.jpg
- assets/Menna_Mohamed_CV.pdf

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. The "View CV" buttons open the PDF from the assets folder in a new tab.
4. GitHub/LinkedIn/Email buttons are clickable.
5. Project GitHub buttons currently point to the GitHub profile because the CV did not contain individual repository URLs. Replace those href values with the exact repository links when available.

The design uses a modern Space Grotesk + DM Sans typography pairing, animated reveal effects, cursor glow, scroll progress, animated tech marquee, floating cards, orbital photo frame and responsive navigation.
